Parameter quick reference
KnobRangeWhat it does
pitch5–89°Camera tilt from horizontal. Low values = dramatic horizon view with long shadows; high values = top-down map.
yaw0–360°Camera rotation around the model. Rotates which tensor families face the viewer.
dist_factor0.8–6×Camera distance from terrain centre. Small = close-up detail; large = full overview (use 3–4 to frame the whole expert massif).
lens20–120 mmFocal length. Wide (20–35 mm) = dramatic perspective with visible depth; tele (80+ mm) = compressed, flat, more map-like.
z_scale0.5–30Height exaggeration. Higher values make the relief more dramatic; lower values keep the terrain closer to the data's true proportions.
gamma0.5–3Height curve. Below 1 lifts valleys and compresses peaks; above 1 emphasizes peaks and deepens valleys.
sun_alt2–80°Sun altitude above the horizon. Low values = long dramatic shadows (golden hour); high values = flat overhead lighting.
sun_azi0–360°Sun compass direction. Rotates which side of the terrain is lit vs shadowed.
resolution400–4096 pxOutput image width in pixels. 1800 is fine for the UI; 4096 for publication-quality exports.
samples16–1024Cycles quality. More samples = less render noise but slower (each render is minutes on CPU).
labelson/offPeak annotations: white glowing labels at each tensor family's densest cluster (e.g. "expert massif", "attention", "n-gram").

Each distinct parameter set produces a separate embedding_terrain_<hash>.png; older renders are conserved. The file without a hash always shows the latest render.
